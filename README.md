# Broken Arrow House

George and Bunny's house at 3120 Broken Arrow Rd, Borrego Springs, in 3D: the existing house, the proposed west addition, the pool court and the flood grading, on the real ground (USGS 3DEP + Esri imagery).

Live: https://shopnerd.github.io/broken-arrow/

Built from the scripts in the Broken Arrow Drive folder (`site-data/`): build_will.py → make_viewer.py → apply_design.py → palms.py → hardscape3d.py, then copy `viewer/index.html`, `data.json`, `aerial.jpg` here and push.
